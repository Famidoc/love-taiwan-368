## 二、 快速上手：將 App 安裝到手機與電腦桌面 (PWA)
本 App 採用最先進的 PWA (Progressive Web App) 技術，**無需透過 App Store 或 Google Play**，即可直接安裝為獨立 App，享受全螢幕、離線使用與極速啟動體驗！

### 📱 1. iPhone / iPad (iOS Safari)
1. 使用 **Safari 瀏覽器** 開啟網址：`https://famidoc.github.io/love-taiwan-368/`
2. 點擊螢幕底部的 **「分享按鈕」**（方形箭頭向上圖示）。
3. 往下滑動，選擇 **「加入主畫面」** (Add to Home Screen)。
4. 點擊右上角「新增」，手機桌面上就會出現綠金專屬的 368 台灣圖示！

### 🤖 2. Android 手機 (Chrome)
1. 使用 **Chrome 瀏覽器** 開啟網址。
2. 點擊右上角「⋮」選單，或點擊瀏覽器跳出的提示 **「安裝應用程式」** 或 **「加到主畫面」**。
3. 確認安裝後，即可在手機桌面獨立開啟。

### 💻 3. Windows / Mac 電腦 (Edge / Chrome)
1. 開啟網頁後，點擊網址列右側的 **「安裝」** 圖示（或在右上角選單選擇「應用程式」$\to$「安裝此網站為應用程式」）。
2. 即可在桌面建立捷徑，享有像原生軟體般的獨立全螢幕視窗。

## 三、 核心功能操作詳解

### 3.1 鄉鎮圖鑑與全台可視化地圖
- **分區快速篩選**：頂部提供「全部、北部、中部、南部、東部、離島」快速切換。
- **縣市精準選擇**：支援 22 個縣市下拉選單。
- **狀態過濾**：可篩選「全部、已完成 (6/6)、探索中 (1~5)、未造訪 (0)」。
- **搜尋引擎**：支援輸入郵遞區號、鄉鎮名（例如：`南區`、`二水`）、景點名或美食名稱即時搜尋。
- **地圖模式**：點擊頂端「地圖」按鈕，可切換為全台灣分區互動地圖，點擊縣市即可自動展開該縣市所有鄉鎮。

### 3.2 景點與美食打卡（支援 Google Maps 一鍵導航）
- 每個鄉鎮卡片皆列出「3 大必訪景點」與「3 大必吃美食」。
- 點擊任一項目即可切換完成狀態。
- 每個項目旁皆附有 **Google Maps 圖標**，點擊後會直接在 Google 地圖中定位該景點或店家，方便旅途中立即導航！

### 3.3 拍攝佐證照片與相簿上傳（極速高畫質壓縮）
- 點擊卡片底部的 **【記錄 / 拍照】** 開啟手帳燈箱。
- 支援 **相機即時拍照** 或 **從手機相簿選取照片**（每個鄉鎮上限 6 張，對應 3 景點 + 3 美食）。
- 內建智慧壓縮引擎：即便使用 4800 萬高畫素旗艦手機拍照，系統也會在 0.1 秒內自動完成畫質保真壓縮，避免佔用手機容量與記憶體。

### 3.4 撰寫隨手筆記與星級評分
- **體驗評分**：提供 1 至 5 星評分，記錄您對該鄉鎮的感動程度。
- **隨手筆記**：記錄店家私房菜、營業時段、沿途私房路線或心情小語。

### 3.5 未儲存智慧防呆保護機制 🛡️
- 當您拍照、勾選景點或輸入心得後，若不小心誤觸右上角 `[X]` 或「取消」按鈕：
- 系統會自動彈出防呆警示視窗，提供 **【儲存紀錄並關閉】**、**【放棄本次修改】**、**【返回繼續編輯】** 三種選擇，確保珍貴的旅遊紀錄與照片永不遺失！

## 四、 拍立得足跡成就卡生成與社群分享
1. 在鄉鎮卡片底部點擊 **【📸 拍立得】**（或在打卡燈箱點擊「儲存並生成拍立得」）。
2. 系統會自動為您組裝出帶有復古拍立得邊框的專屬成就卡片：
   - 包含：鄉鎮標題、代表佐證相片、星級評分、打卡日期、完成度印章、您的稱號徽章與專屬 QR Code。
3. 點擊 **【下載高清圖片】** 即可儲存圖檔至手機相簿。
4. 點擊 **【分享足跡】** 可直接發送至 LINE 好友、Facebook、Instagram 或 Facebook 社團！

## 五、 各區「先行者」名錄與全台風雲榜

### 5.1 查閱鄉鎮先行者名錄
- 在每張鄉鎮卡片右上角點擊 **`👥 先行者`** 按鈕。
- 即可打開該鄉鎮專屬的行腳名冊，查閱有哪些同好已經踏訪此地、他們的完成度與插旗時間！

### 5.2 參與全台同好排行榜（免登入、零門檻）
- 點擊頂部導覽列的 **【🏆 排行榜】**。
- 系統自動以即時連線（Google Apps Script 試算表技術）呈現全台行腳旅人的踏破鄉鎮數與百分比排名。
- **完全不需要綁定任何帳號**，只要在名片設定中儲存暱稱，任何人打卡後都能即時入榜！

### 5.3 自訂個人行腳名片與頭像
- 在排行榜中切換至 **`👤 我的名片`** 分頁。
- 可自訂同行者暱稱（例如：*單車阿文*、*美食小護士*）、挑選 12 款趣味代表頭像、撰寫行腳宣言，以及切換是否公開參與排行。

### 5.4 「我的踏破清單」足跡手帳與一鍵跳轉
- 在排行榜中切換至 **`🗺️ 我的踏破清單`** 分頁。
- 頂端統計您的全台踏破率、全制霸鄉鎮數與總打卡景點數。
- 清單列出您已踏破的所有鄉鎮、照片縮圖與心得。
- **一鍵跳轉**：點擊清單中任一鄉鎮，App 會自動為您跳轉定位至該鄉鎮卡片！

## 六、 個人雲端無感備份與跨裝置同步 (Google Drive)
為了讓您在「電腦端」與「手機端」之間無縫同步私人照片與旅遊日記，App 提供了 Google Drive 雲端同步功能：

1. 點擊頂端導覽列的 **【☁️ 同步】** 按鈕。
2. 點擊 **【登入 Google 帳號授權備份】**，授權將資料安全儲存於您個人的 Google 雲端硬碟。
3. **無感自動備份**：授權完成後，未來只要您在 App 中有任何打卡、拍照或筆記變更，系統會在 2 秒後於背景**自動上傳備份**（右上角圖示會顯示「同步中」$\to$「已同步」）。
4. **跨裝置自動復原**：在另一台設備（例如由電腦換到手機）打開 App 並登入同一 Google 帳號，系統會自動比對時間戳記，智慧下載最新進度！
5. **本地檔案備份**：若不想使用 Google 帳號，亦可在同步視窗中點擊 **【匯出本地 JSON 備份檔】** 自行存檔。

## 八、 常見問題與疑難排解 (FAQ)

### Q1：如果沒有網路（例如在深山或離島），App 還能打卡與拍照嗎？
**A**：完全可以！本 App 採用「離線優先」架構，所有打卡與照片會優先安全存放在手機內部的 IndexedDB 資料庫中。等回到有網路環境時，雲端備份與排行榜會自動在背景補行同步。

### Q2：排行榜中為什麼完全不用登入 Gmail 就能看到其他人？
**A**：排行榜是透過輕量化的公開連線資料庫運作，每個裝置會自動配發匿名 ID，兼顧「零門檻快速參與」與「極致隱私安全」，不收集任何個人 Email。

### Q3：如何把我的打卡紀錄轉移到新買的手機？
**A**：只要在舊手機上點擊【☁️ 同步】登入 Google 帳號完成備份；在新手機打開 App 登入同一個 Google 帳號，所有進度與照片就會自動完整還原！

### Q4：照片上傳有數量限制嗎？會不會讓手機跑很慢？
**A**：每個鄉鎮市區支援最多 6 張照片（3 景點 + 3 美食，全台共可收納高達 2,208 張足跡相片）。App 內建高效壓縮演算法，每張照片會自動最佳化，既清晰又輕巧，完全不卡頓。
