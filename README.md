# 🇹🇼【愛台灣 368 行腳】踏破手帳 PWA

專為「走遍台灣 368 個鄉鎮市區」打造的高質感足跡記錄與社群打卡 PWA 應用。

## ✨ 核心特色功能

1. **📊 368 完整母表資料庫**：
   - 收錄全台 368 個三級行政區（市轄區、鎮、鄉、直轄市山地原住民區）。
   - 包含 **1,104 個必訪景點** 與 **1,104 種在地必吃美食**，隨手勾選打卡。

2. **🗺️ 22 縣市足跡點亮地圖**：
   - 視覺化互動台灣地圖，完成各鄉鎮打卡即時點亮著色。
   - 支援依五大地理分區（北部、中部、南部、東部、離島）與 22 縣市快速切換與篩選。

3. **📝 隨手記與相片佐證（極速輕量）**：
   - 支援 1~5 星級評分、造訪日期選擇、旅行隨手筆記。
   - 上傳 1~3 張佐證照片時，瀏覽器前端會自動壓縮為輕量高清 WebP 格式，存入手機 IndexedDB，數千張照片依然流暢不卡頓。

4. **📸 成就拍立得卡片一鍵生成**：
   - 利用 HTML5 Canvas 動態合成復古拍立得足跡卡（包含鄉鎮名稱、官方踏破紅色戳印、照片、評分、全台進度條）。
   - 支援一鍵下載 PNG 圖檔，或直接透過手機 Web Share API 分享至 LINE 群組與 FB 社團。

5. **🏆 368 行腳同好榮譽榜**：
   - 支援全台踏破進度即時排行。
   - 徽章頭銜體系（環島傳奇、行腳大師、百岳行者、行腳先鋒、探路新星）。
   - 個人名片客製化（自選 Emoji 頭像、暱稱、行腳宣言、公開/匿名切換）。

6. **☁️ 雙軌雲端同步與備份**：
   - **Google Drive 個人私有同步**：使用使用者自己的 Google 雲端硬碟備份，完全不佔創作者伺服器空間，無後續費用。
   - **一鍵 JSON 檔案匯出/匯入**：100% 離線可用，換手機或電腦一秒還原。

7. **👥 社群交流平台直達**：
   - 整合 LINE 官方社群與 FB 粉絲專頁/社團入口。

---

## 🚀 啟動方式

在專案目錄 `D:\antigravity\love-taiwan-368` 下執行：

```bash
npm run dev
```

瀏覽器打開 `http://localhost:3000` 即可開始使用！

若要重新從 Google 試算表更新資料：
```bash
npm run parse:data
```
